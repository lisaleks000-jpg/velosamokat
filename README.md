# Везём тем, кто не вывозит

Страница кейса: спекулятивная кампания для сервиса доставки «Велосамокат».
Статичный сайт без сборки: один `index.html` и картинки. Подходит для GitHub Pages как есть.

## Что внутри

- `index.html` — вся страница: вёрстка, стили и небольшой скрипт, который не даёт коротким словам висеть в конце строки.
- `img/` — обложка, фото и мокапы наружки.
- `img/board/` — картинки для доски в первой главе.
- `og.jpg` — превью, которое показывается, когда ссылку отправляют в мессенджер или соцсеть.
- `favicon.svg` — иконка вкладки.
- `.nojekyll` — служебный файл: говорит GitHub Pages отдавать файлы как есть.

## Перед публикацией

1. Контакты. В `index.html` замените `your_telegram` и `you@example.com` (каждый встречается два раза).
2. Превью. В `index.html` замените `USERNAME` и `REPO` в тегах `og:image` и `og:url` на адрес страницы.
3. Подпись к комиксу про энергию на доске: если найдётся автор, добавьте его в `alt` или в подпись.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки (файлы должны лежать в корне, рядом с `index.html`).
2. Settings → Pages → Build and deployment: Source — Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту страница откроется по адресу `https://USERNAME.github.io/REPO/`.
